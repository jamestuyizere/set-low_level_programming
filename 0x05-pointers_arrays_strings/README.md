# Pointers, Arrays and Strings

This project contains C programming exercises focused on
pointers, arrays, strings, and memory operations.

## Task 0: 98 Battery st.

The reset_to_98 function receives a pointer to an integer
and updates the value stored at that address to 98.

## Files

- main.h: Function prototypes
- 0-reset_to_98.c: Updates an integer through a pointer
